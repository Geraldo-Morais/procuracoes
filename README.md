# Procurações

Gerador de procurações e documentos do escritório.

**Acesso:** https://geraldo-morais.github.io/procuracoes/

## Estrutura

- `index.html` — geração dos documentos;
- `revogacao.html` — revogação de procuração;
- `assets/` — arquivos visuais;
- `data/` — dados públicos usados pela interface.

Não inclua documentos ou dados de clientes neste repositório.
